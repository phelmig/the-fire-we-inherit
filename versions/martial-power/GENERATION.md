# Generation Parameters — Martial Power

Per-track generation settings. This version runs hot: weirdness 40–60
(validated — the martial sound holds its identity and gains character at high
weirdness; the old global 15 was tuned for multi-voice opera casts this
version no longer uses). Style influence stays 95 everywhere.

## Exclude sets

Philosophy (ALL tracks): keep exclusions minimal — at high weirdness,
freedom helps; exclude only absolutely unfitting elements and escalate
per track only if drift actually appears on that track.

- **MINIMAL** (universal default): `pop, EDM`
- **ARMOR** (anti-folk escalation, apply per track only after observed
  drift): `pop, soft rock, acoustic guitar, nylon-string guitar, folk, Irish folk, celtic, folk metal, fiddle, tin whistle, bagpipes, accordion, flute, EDM, opera`
