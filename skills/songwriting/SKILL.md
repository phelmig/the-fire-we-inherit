# Songwriting Workflow

1. Read `PLAN.md` and the immediately preceding/following song drafts before changing a track.
2. Preserve the track's dramatic job and at least one recognizable refrain or motif.
3. Define no more than the needed vocal forces. Keep the Suno style prompt free of character names and voice mapping; use it only for musical direction. In the lyrics, label every vocal entry—including choirs and narration—with the character or role name followed by the vocal description: `[CHARACTER OR ROLE — Gendered vocal type, register/resonance, delivery]`. Examples include `[ZEUS — Male subterranean basso profundo, slow and immovable]` and `[CHORUS — Female icy contralto, distant and mournful]`. A name or role alone is not reliable voice mapping.
4. Build the song as theatrical interaction: compact accusations, questions, interruptions, choir answers, and one repeated memorable hook.
5. Keep directions useful but lean. Validate total lyric text below 5,000 characters, preferably 1,800–3,000.
6. Check continuity: every fire/chain/open-hand image must gain meaning, and a creator must never be treated as entitled to own what it created.

## Structure requirement after track 04

Track 05 establishes that fear may warn the hand but must never rule it; law may protect the living but must not close the future. Tracks 06–09 show humanity becoming a maker in turn. Track 10 is the final moral trial, informed by all prior evidence. Track 11 is a recursive spoken epilogue, carrying the open-hand question beyond humanity without presenting the Future Intelligence as a god or a replacement for humanity.

## File format

Each song file contains a title heading, a `Style` code block, and a `Lyrics` code block. Use two-digit play order in both filename and title, except for the current user-approved provisional split `02a` / `02b`.
